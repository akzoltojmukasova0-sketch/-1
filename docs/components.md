# Описание компонентов

Названия компонентов совпадают с названиями на схеме `architecture.png`.

## Клиентский уровень (представление)

| Компонент | Назначение | Технология | Взаимодействует с |
| --- | --- | --- | --- |
| Диспетчер | Создаёт маршруты, добавляет доставки, назначает курьеров и транспорт; без этой роли в системе не появляются плановые данные | Браузер | React SPA |
| Курьер (с телефона) | Отмечает статусы доставок и передаёт GPS-координаты; это источник фактических данных для оценки | Браузер телефона | React SPA |
| Менеджер по логистике | Запрашивает оценку эффективности, смотрит дашборд и отчёты; ради этого результата система и создаётся | Браузер | React SPA |
| Администратор | Управляет пользователями, транспортом, складами, нормативами и весами KPI; без него формулу нельзя настраивать без изменения кода | Браузер | React SPA |
| React SPA | Единый интерфейс: панель диспетчера, режим курьера на телефоне, дашборд KPI, отчёты. Отправляет запросы к API и показывает ответы; без него пользователь не смог бы работать с системой. В нём нет расчётов и доступа к БД | React, TypeScript | Backend (HTTPS, REST, JSON) |

## Серверный уровень (приложение, NestJS)

| Компонент | Назначение | Технология | Взаимодействует с |
| --- | --- | --- | --- |
| Auth + Guards | Проверяет подпись и срок JWT и роль пользователя (RBAC) до выполнения любой логики. Без него любой пользователь мог бы вызвать любую операцию, например изменить веса KPI | NestJS Guards, JWT | React SPA, Controller |
| Controller (REST API) | Принимает HTTP-запросы, проверяет формат данных (DTO) и передаёт их в Service нужного модуля. Отделяет работу с HTTP от бизнес-логики | NestJS Controllers, class-validator | Auth + Guards, модули |
| Auth / Users | Регистрация и вход, хэширование паролей (bcrypt), выпуск JWT, хранение профилей и ролей | NestJS, bcrypt, JWT | ORM — Prisma |
| Fleet | Справочник транспорта (вместимость, тип, расход) и складов. Нужен, чтобы считать загрузку и стоимость | NestJS | ORM — Prisma |
| Routes | Создание маршрутов и доставок, назначение курьера и транспорта, смена статусов, поиск и фильтрация; проверяет, что курьер меняет только свои доставки | NestJS | Integrations, ORM — Prisma |
| Integrations | Единая точка обращения к внешним API: запрашивает у сервиса карт плановый путь и время, кэширует ответы. Без этого модуля вызовы внешних API были бы разбросаны по коду | NestJS, HTTP-клиент | Сервис маршрутов и карт |
| Analytics | Считает пять KPI и итоговый индекс эффективности (0–100), определяет категорию, сохраняет оценку со снимком нормативов; сравнивает план и факт | NestJS | Routes, Tracking, Reference, ORM — Prisma |
| Reports | Формирует отчёты PDF / Excel по оценкам и сравнению план — факт за период. Без него результат нельзя сохранить и передать | NestJS, генератор PDF / Excel | Analytics, ORM — Prisma |
| Reference | Хранит и отдаёт нормативы, веса и пороги KPI; изменения доступны только администратору | NestJS | Analytics, ORM — Prisma |
| Tracking | Принимает и хранит GPS-точки (пакетами), фильтрует выбросы, считает фактический пробег | NestJS | GPS-трекеры ТС, Analytics, ORM — Prisma |
| ORM — Prisma | Единственная точка доступа backend к БД: превращает вызовы модулей в SQL, управляет транзакциями. Без него SQL был бы разбросан по модулям | Prisma | Модули, PostgreSQL (SQL) |

## Уровень данных

| Компонент | Назначение | Технология | Взаимодействует с |
| --- | --- | --- | --- |
| PostgreSQL | 9 таблиц: `users`, `warehouses`, `vehicles`, `routes`, `deliveries`, `gps_tracks`, `efficiency_scores`, `kpi_rules`, `reports`. Внешние ключи и ограничения уникальности защищают данные от ошибок | PostgreSQL | Только backend через ORM (SQL) |

## Внешние сервисы

| Компонент | Назначение | Технология | Взаимодействует с |
| --- | --- | --- | --- |
| Сервис маршрутов и карт | Строит плановый маршрут между точками, возвращает расстояние, время в пути и данные о пробках. Без него плановые значения пришлось бы вводить вручную | Внешний API (Routing / Maps API) | Integrations (HTTPS, JSON) |
| GPS-трекеры ТС (опционально) | Передают координаты и скорость транспорта автоматически, без участия курьера. Если трекеров нет, координаты передаёт телефон курьера | Телематика, HTTPS | Tracking (HTTPS, JSON) |
